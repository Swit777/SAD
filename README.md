# Тема 15 Анализ и обнаружение ложных новостей

## Обновлённый сайт и материалы проекта

Сайт показывает расширенный каталог: **313 354 текста**, включая
252 146 дополнительно собранных. Отдельно хранятся **47 609 записей утверждений**
LIAR и MultiFC, образующих 37 696 точных групп. В разделе «Каталог данных» доступны
поиск по источнику, заголовку и утверждению, просмотр текста и переход к анализу.
Список читает метаданные Parquet, а тело статьи загружается отдельно.

Текущая английская модель обучена на **30 267 размеченных статьях ISOT и WELFake**.
В обучении использованы полные и короткие представления, словесные и символьные
TF–IDF признаки. Для заголовка, короткой заметки и статьи калибровка и порог
раздельные. Объединение учитывает обученные веса участников вместо одинакового
влияния каждой модели. Базовые классификаторы при этой доработке не переобучались.
Из длинной статьи анализируется начало, до 1600 очищенных символов. В обучении
14 683 статьи real и 15 584 fake; два представления одной статьи не считаются
дополнительными реальными новостями.
Группы публикаций не пересекают обучение, настройку, калибровку и проверку.
Категории издателей FakeNewsCorpus и рейтинги FakeHealth не использованы как
бинарные метки; весь каталог не объявлен обучающей выборкой.

На ранее не использованных **4 479 текстах того же корпуса** macro-F1 статей
изменился с **0,938 до 0,949**, ложные обвинения real — с **7,1% до 3,9%**.
Это проверка по отложенным группам, а не по новым издателям.

Результат повторных внешних проверок неоднозначен:

| Проверка | Macro-F1 до / после | Настоящие ошибочно в fake до / после |
|---|---:|---:|
| Celebrity, статьи | 0,522 / 0,631 | 77,6% / 51,6% |
| FakeNewsAMT, статьи | 0,642 / 0,615 | 35,4% / 28,3% |
| FakeNewsNet, заголовки | 0,425 / 0,440 | 66,4% / 63,1% |

На FakeNewsAMT полнота fake снизилась с 63,8% до 52,1%: осторожный порог уменьшает
ложные обвинения, но пропускает больше фейков. По одним заголовкам FakeNewsAMT
macro-F1 остаётся около 0,50. Все три внешних набора уже просмотрены; свежего
независимого внешнего подтверждения нет. Автоматические вердикты отключены.

Результаты: `reports/training_report.json`. Протокол улучшения находится в разделе
`english_improvement` и `refinement` существующего файла в `protocols`.
Проверка текущего проекта: `python scripts/verify_version.py`.
Обучение выполняет `python scripts/train.py`; доработку калибровки и объединения —
`python scripts/train.py --refine` по заранее зарегистрированному плану;
повторное обучение требует нового независимого внешнего теста, а не подбора по
уже просмотренным ответам. Модель заменяется в `artifacts/model.joblib` без копий.

Для запуска подготовленного приложения достаточно `start.bat` либо команды:

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Откройте http://localhost:8501. В разделе «Материалы проекта» можно скачать:

- `deliverables/project_report.docx` — описание реализации, данных и методологии.
- `deliverables/project_presentation.pptx` — презентация для защиты.

Отчёт оформлен по студенческому образцу. Отчёт и презентация описывают текущую
модель, три формата ввода, результаты калибровки, анализ ошибок и ограничения
повторной внешней проверки. Файлы обновляются на прежних местах в `deliverables`.
